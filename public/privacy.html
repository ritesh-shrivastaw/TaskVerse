Privacy policy

Last updated October 1, 2026

This page explains what happens when you use the classroom project demos on this website.

Prompts and generated content

When you use a generation demo, the text you enter and the related instructions are sent to this site's server, then forwarded to Google Gemini to produce a response. The Gemini API key is kept on the server and is not sent to your browser. Do not enter passwords, private records, or other sensitive information into a demo.

Google processes API requests under its applicable terms and data policies. Review Google's current Gemini API terms before using the demos with information that needs special protection.

Website operation

The server applies a temporary per-IP request limit to the Gemini endpoint. The limit counter is held in server memory and expires after one minute. This application does not include analytics or advertising code.

The hosting provider may process connection information in routine server logs. What is collected and how long it is retained depends on the provider and deployment configuration used to publish the site.

Fonts and external requests

The site requests DM Sans, Fraunces, and IBM Plex Mono from Google Fonts. Those requests go to Google and may disclose standard connection information, such as your IP address. The site does not use tracking cookies.

Policy updates

This policy may be updated when the site's features or hosting practices change. Check the date above to see when it was last revised.
